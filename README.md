# 無限ころりんスロープ（kororin-slope）

ビルド工程なしの静的ファイル構成です。Three.js r160 を `vendor/` に同梱しています（CDN 不使用）。

## ローカル確認手順
ES Modules を使うため、`file://` ではなく簡易サーバー経由で開きます。

```
cd kororin-slope
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 構成
- `index.html` / `style.css` … 画面
- `js/main.js` … レンダラー、ループ、リサイズ、DPR 上限、品質切り替えの適用
- `js/world.js` … シーン（空・チャンクの地形メッシュ・球・ライト・カメラ）。フローティングオリジンに合わせて位置を更新
- `js/physics.js` … 自前物理（シード付き高さ関数・チャンク生成/破棄・フローティングオリジン・固定 1/120 s）。Three.js 非依存
- `test.js` … `node kororin-slope/test.js`（5 km 走破・決定論・原点移動の一致・放物運動・バイオーム・装飾・世界の通し実行）。`package.json` は ES Modules 指定
- `js/biomes.js` … 距離で切り替わるバイオームの補間（Three.js 非依存）。花畑→雲海→夕焼けの丘→夜の星空→（朝になって）花畑…と周回し、昼・夕・夜の移り変わりもこれで表現
- `js/decor.js` … 丸い装飾（木・花・雲・丘）の配置（決定論）と、チャンクごとの頂点カラーメッシュ化
- `js/scenery.js` … 空のグラデーション・星・遠景の丘・花びら/綿毛のパーティクル
- `js/onigiri.js` … おむすび本体（丸い三角の形状、米粒・海苔のテクスチャを Canvas で自前生成、縁のほんのり明るさ、着地のつぶれバネ）
- `js/camera.js` … 自動追従カメラ（ショット切り替え・ゆらぎ・速度で引く）とドラッグ／ホイール／ピンチ操作。Three.js 非依存の部分は Node でテスト可能
- `js/obstacles.js` … 障害物（もちもち・ふわふわキノコ・丸岩）のシード付き配置、球との衝突（押し出し＋反発）、バネの揺れ。Three.js 非依存
- `js/split.js` … 分裂（ぽんっと増える・上限8個・小さい子が付いて転がる・離れたらフェード・寿命で合流）。Three.js 非依存
- `js/obstacle-view.js` / `js/split-view.js` … 障害物と子の見た目（揺れ＝つぶれ・のび、ぽんっ・合流・フェードの演出）
- `js/fillings.js` … 具の定義（通常12種＋レア3種）、距離帯ごとの抽選、レアイベント。Three.js 非依存。確率はシードに依存せず、乱数関数を渡して抽選
- `js/records.js` … 最長記録・ずかんの localStorage 保存（壊れたデータ・保存不可でも落ちない）と、距離に応じた進行管理。Three.js 非依存
- `js/post.js` … ポストエフェクト（軽いチルトシフト・ブルーム・ヴィネット）。シーンを一度バッファに描いて重ねる自前実装。使えない環境・画質「低」では通常描画
- `js/audio.js` … WebAudio 合成の音（環境音の和音・風・転がる音・着地／ぶつかり／分裂／合流／具の発見／レアの効果音）。外部音源なし。最初の操作のあとに鳴り始め、ミュートは記憶される
- `js/shot.js` … 撮影（UI なし PNG、距離・具・タイトル入りのシェア画像。対応端末は共有シート、なければ保存）
- `js/ui.js` … 品質トグル（高/中/低）、具ずかん（未発見はシルエット）
- `js/config.js` … 調整用定数（`SIM`：坂・物理、`OBSTACLES`：障害物の種類・大きさ・弾み・揺れ、`SPLIT`：分裂の頻度・上限・寿命・フェード、`CAMERA`（自動ショット・操作感）、`ONIGIRI`（形・海苔・縁の光・つぶれ）、`QUALITY_LEVELS`：品質、`BIOMES`/`WORLD`：バイオームの色・長さ、`PALETTE`、`FILLING`：具の変わる距離・レア確率・イベント確率・保存間隔）
- `vendor/three.module.min.js` … Three.js r160（MIT、`vendor/LICENSE-three`）

操作：←→ / A D、またはタッチ・クリックで画面の左右。ドラッグでカメラ回転、ホイール／ピンチで寄り引き（離すと自動追従に戻ります）。`?seed=数字` でシードを変えられます。

## 画面のボタン
画質（高／中／低）・効果（ポストエフェクトのあり／なし）・音（あり／なし）・ずかん・撮影。設定は端末に記憶されます。
撮影モードでは UI が消え、「PNG保存」（画面のみ）と「シェア画像」（距離・具・タイトルの帯つき）が使えます。「もどる」または Esc で戻ります。
スマホの縦・横どちらでも使えるよう、ボタンは折り返し、ノッチ（セーフエリア）を避けて配置します。

## 公開の下準備（素子さん向け）
- すべて相対パスなので、`kororin-slope/` フォルダをそのまま置けば、サブパス（例：GitHub Pages の `https://…/リポジトリ名/kororin-slope/`）でも動きます。ビルド不要、外部サービス・CDN・外部音源は使っていません（`node kororin-slope/test.js` が絶対パス・外部 URL の混入も検査します）
- 読み込みに失敗したとき（ファイル欠け・通信切れ・`file://` で開いた・WebGL が使えない）は、案内のメッセージと「もういちど読み込む」ボタンが出ます
- 初回起動：幕がひらき、タイトル→操作ヒント→ふっと消える（約10秒）。初回だけカメラ操作の案内も出ます
